# ElectraPro — Electrical Engineering Academy

A Streamlit learning platform for Electrical Engineering & Technology, organized from fundamentals to advanced subject pathways.

## Features
- Clean homepage and subject-based learning library
- Subject map with Basic → Advanced progression
- Detailed foundational lessons with worked examples and suggested answers
- Practice questions and quizzes
- Ohm's law, DC power and balanced three-phase power calculators
- Career roadmaps, glossary and textbook/standards references
- Safety-first educational notices

## Run locally
1. Install Python 3.10 or newer.
2. Install dependencies:
   `pip install -r requirements.txt`
3. Start the app:
   `streamlit run app.py`

## Deploy to Streamlit Community Cloud
1. Upload the project files to a GitHub repository.
2. In Streamlit Community Cloud, choose **New app**.
3. Select the repository, branch (`main`) and main file path (`app.py`).
4. Click **Deploy**.

## Project structure
- `app.py` — application interface and page navigation
- `content/curriculum.py` — subject map, original lesson content and quizzes
- `requirements.txt` — dependencies
